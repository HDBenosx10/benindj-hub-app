# BeninDJ Hub 0.9.0

- Percurso por módulos visível em Minha trilha, com competências e referências oficiais.
- 46 aulas revisadas no Professor; 185 exercícios e 90 missões, com transferência fora do Hub.
- Aulas HTTP com mapa; aulas 39–45 com mock HTTP real; aulas 40–45 com o mesmo banco SQLite no servidor e na lateral.
- Desafios adicionais de recursão, busca binária, instâncias e microtarefas.
- Aluno inclui somente Hello World. Aulas futuras e gabaritos permanecem sob controle do professor.

## Qual arquivo baixar

Use o arquivo com **Instalador** para instalar uma vez e abrir pelos atalhos. Use **Windows-x64.exe**, sem Instalador no nome, para abrir a versão portátil. Ambas incluem o runtime; não exigem Node nem Docker. Dados são mantidos fora da instalação.

## Onde está a bancada visual

No Professor, abra a aula 39, ou qualquer aula 40–45. O mapa aparece em Entender; banco e API simulada ficam na lateral. Execute o projeto antes de inspecionar as tabelas criadas por ele. O Aluno vê esses recursos somente depois de importar a aula liberada. Se recebeu uma versão antiga da aula, importe o arquivo atualizado.
